Mesh interfaces

Link this node to the Reticulum mesh. Add a TCP client to dial a relay, a TCP server to be a relay, or LAN auto-discovery to find neighbours on the local network. Each may be IFAC-protected so only peers sharing the network name and passphrase can talk on it. Interfaces added here are saved and re-attached on restart.

This node has no [uplink], so there are no uplink interfaces to configure here. That is a different thing from hosting games on the mesh: [uplink] is the control destination an index drives this node through, while [mesh] is what announces the games this node runs. Games can be on the mesh with no uplink at all — the panel below says whether yours are.
