Game packs

A pack tells Lanthorn how a game talks: its ports, its query, where its files come from. It never names a program to run. These are the official packs, reviewed before they are merged and signed with the project key.

Packs

Use them

Lanthorn and Lanthorn Host read this repository by default, and pick up a pack the day it is published. Its address is:

https://idan2025.github.io/gaming-platform-prns/packs/

Every list and pack is signed by the project key, and Lanthorn refuses a list this key did not sign:

7a656c1da3347bfcfe6b3981f71099c8

Mirror them

A mirror is an exact, one-way copy. It cannot add to or change the official list: the signatures it carries are the project's, so an edited file fails them everywhere.

game-bridge repo mirror ./lanthorn-packs

Run it again to take what was published since. Serve the folder from any web host, or add the folder itself in Lanthorn or Lanthorn Host to work with no internet at all.

Or seed it over Reticulum, so launchers and nodes on your mesh get the official packs with no internet:

game-bridge repo seed ./lanthorn-packs --official --auto

Add a game

Open a pull request that adds a .toml to packs/. CI runs game-bridge review on it and posts the result on the pull request; it refuses what no honest pack needs, and a maintainer reads the rest. Once merged it is signed and published here. How to add a game · Request one

Passing review does not make a pack safe; the format does: a pack cannot name a program, and its launch arguments start the player's own game without a shell.
